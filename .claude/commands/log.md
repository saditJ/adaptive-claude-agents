# /log — View the full project team activity log

Read TEAM_LOG.md and display its contents clearly.

Format the output as:
```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
TEAM LOG — [project name]
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

[date] | [agent]        | [file] — [description]
[date] | [agent]        | [file] — [description]
...
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Total tasks logged: [n]
Most active agent: [agent with most entries]
Last activity: [most recent date]
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

If TEAM_LOG.md doesn't exist yet:
"No activity logged yet. Run /start to set up your team and begin working."

This is read-only. No changes are made.
